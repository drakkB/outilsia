Aide pour OutilsIA dans ChatGPT

Le support couvre le serveur MCP, ses quatre outils en lecture seule et les rapports publics OutilsIA. L'installation locale reste prise en charge par Local Cockpit.

Vérification rapide

  1. Vérifier l'URLLe serveur doit être ajouté avec https://outilsia.fr/mcp.
  2. Ouvrir une nouvelle conversationAprès toute modification du connecteur, rechargez le plugin et démarrez un nouveau fil.
  3. Donner un profil completCPU, RAM, GPU et VRAM sont obligatoires pour une estimation.
  4. Utiliser un rapport exactSeules les URL HTTPS https://outilsia.fr/r/… sont acceptées.

Ce que le support peut diagnostiquer

Connexion MCP

Initialisation, liste d'outils, schémas ou réponse du serveur.

Profil refusé

Champ obligatoire absent, valeur impossible ou format incorrect.

Rapport introuvable

Lien étranger, token invalide, rapport désactivé ou machine supprimée.

Fiche visuelle

Rendu incomplet, action externe ou problème d'affichage mobile.

Ce que le connecteur ne fait pas

Il ne peut pas dépanner un pilote NVIDIA/AMD/Intel, ouvrir Ollama, installer WSL, télécharger un modèle ou lancer un benchmark. Pour ces actions, utilisez OutilsIA Local Cockpit et sa console locale.

Signaler un problème

Utilisez la page Contact OutilsIA. Indiquez : l'heure approximative, le nom de l'outil, le message visible, votre navigateur/OS et un exemple sans donnée privée. Ne joignez ni clé API, ni mot de passe, ni document personnel.

Questions fréquentes

Pourquoi ChatGPT demande-t-il le matériel ?

Le connecteur ne scanne pas votre PC. Il a donc besoin du CPU, de la RAM, du GPU et de la VRAM pour produire une estimation.

Pourquoi mon rapport n'affiche-t-il aucun tokens/s ?

Les anciens rapports peuvent ne pas contenir de benchmark structuré. OutilsIA préfère afficher « benchmark à faire » plutôt qu'inventer une vitesse.

Pourquoi l'installation demandée dans ChatGPT n'est-elle pas lancée ?

Parce que tous les outils MCP OutilsIA sont en lecture seule. L'installation exige une action explicite dans l'application desktop.
